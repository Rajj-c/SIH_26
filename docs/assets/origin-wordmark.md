# Origin Point wordmark

`components/shared/origin-logo.jsx` renders fixed vector artwork for the words
ORIGIN and POINT using Ethnocentric Rg, with the supplied black-circle infinity
symbol between them. `origin-lettering.json` stores one compound path per
complete word. Text remains accessible through the component's image label.

Source: Typodermic's official free desktop collection, `typodermic-free-fonts-2026i.zip`,
Ethnocentric Rg.otf (downloaded 13 October 2026).

The font software is not included or served to browsers. The output is fixed
logo artwork, covered by the designer's desktop artwork usage:
https://typodermicfonts.com/license/

Use the shared component for brand placements; ordinary mentions in prose stay
as text. Size the component with text-size utilities and use `currentColor` for
light/dark surfaces.
